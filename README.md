# 多语言应急通知撰写与发布前检查工具

面向应急值班、编辑、法务、翻译和发布人员的纯前端发布工作台。项目可离线起草，数据自动保存到浏览器 `localStorage`，刷新或断网后继续编辑。

## 功能

- 按事件类型、严重程度、影响范围、时间窗口和发布渠道配置通知。
- 简体中文、英文、日文等多语言版本并列编辑，可标记必需语言和翻译复核状态。
- 内置台风转移、计划停水、公共安全三类可复用模板。
- 发布前检查必填字段、禁用词、术语一致性、时间冲突、语言缺失和未解决讨论。
- 编辑、法务、翻译、发布人四类角色确认和退回流程。
- 逐句选择正文并添加、解决讨论。
- 锁定最终版本、从锁定稿发起紧急修订，并保留历史版本。
- 基于 LCS 的两版逐句差异比较。
- 断网续作合并：两台设备各自修改同一通知，网络恢复后以整包续作合并——
  - 不同语言版本直接并入；同一语言只有一边改过则按版本向量取较新，晚到整包不会覆盖另一端；
  - 同一语言两边都改过则并列待裁定，裁定前当前正文保持不变，也不能生成锁定版本；
  - 裁定或语言复核变化后，发布检查结果与版本差异立即失效重算；
  - 本地写入失败时回滚存储并保留合并草稿，可重试写入；
  - 旧数据迁移时自动补齐修订号与版本向量，重复回连同一整包不会多出语言版本或锁定版本。
- `Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Shift+Z` 或 `Ctrl/Cmd+Y` 重做、`Ctrl/Cmd+S` 手动保存。

## 技术栈

- Angular 19 + TypeScript
- Nebular UI
- Angular Forms / RxJS
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run start
```

开发服务器监听 `4200`，宿主端口仅由部署时映射，源码未写入 `10025`。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist/emergency-notice/browser`。

## 合并语义自检

```bash
npm run verify:merge
```

直连 `src/app/notice-sync.ts` 与 `src/app/notice-migrate.ts`，覆盖不同语言并入、晚到整包不覆盖、
同语言双边改动并列待裁定、裁定后重复回连稳定、锁定版本按修订号去重、旧数据迁移幂等等场景。

## Docker

```bash
docker build -t sologsb-1025 .
docker run --rm -p 10025:80 sologsb-1025
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10025`。数据仅保存在当前浏览器，不会上传服务器。
